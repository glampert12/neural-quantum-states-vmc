# Neural Quantum States with Variational Monte Carlo

**Semester Project — ETH Zurich, Institute for Theoretical Physics**  
September–December 2026 · Work in Progress

This project investigates neural-network-based variational wave functions for
quantum many-body systems using **Variational Monte Carlo (VMC)**.

The goal is to implement and compare different **Neural Quantum State (NQS)**
architectures and study their ability to approximate ground states of quantum
spin systems.

## Project Overview

The project combines numerical many-body physics with modern machine learning.
Variational wave functions are represented by neural networks and optimized
using Variational Monte Carlo and stochastic reconfiguration.

Reference methods are used to benchmark the variational results.

### Current work

- Variational Monte Carlo (VMC)
- Stochastic Reconfiguration (SR)
- Neural Quantum States (NQS)
- Restricted Boltzmann Machine (RBM) baseline
- Alternative neural-network architectures
- Exact Diagonalization (ED) benchmarks
- Density Matrix Renormalization Group (DMRG) benchmarks
- Transverse-Field Ising Model (TFIM)
